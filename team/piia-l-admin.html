GitHub 연결

변경사항을 실제 라이브 사이트에 올리려면 GitHub 개인 접근 토큰(Personal Access Token)이 필요해요. 여기서 새로 발급받을 때 "Only select repositories" → 이 저장소(Global-Design-Leadership-Associationv2) 선택 → Repository permissions에서 Contents: Read and write로 설정해주세요. 토큰은 이 브라우저에만 저장되고, GitHub에만 전송돼요 (다른 곳으로 전송되지 않아요).

저장된 토큰 없음 — Publish 전까지는 로컬 편집만 가능해요.
